# 港股筹码跟踪：美团-W（3690.HK）与通用港股代码

## 项目与命令

项目默认位于 `~/hk-stock-tracker`，可通过 `HK_STOCK_TRACKER_HOME` 指定项目目录，兼容旧变量 `MEITUAN_TRACKER_HOME`，新变量优先。使用纯标准库和系统 python3：

```bash
# 每日分析（收盘后）：拉数据→算筹码→事件检测→规则建议→落盘
python3 "${HK_STOCK_TRACKER_HOME:-${MEITUAN_TRACKER_HOME:-$HOME/hk-stock-tracker}}/hk_stock_tracker/tracker.py" daily

# 日内分析（盘中）：VWAP/分时筹码/ORB/量能/相对强弱→日内操作立场
python3 "${HK_STOCK_TRACKER_HOME:-${MEITUAN_TRACKER_HOME:-$HOME/hk-stock-tracker}}/hk_stock_tracker/tracker.py" intraday
```

跟踪其他港股时，先用 init 生成该标的的关键位草稿，再跑日报/日内：

```bash
python3 "${HK_STOCK_TRACKER_HOME:-${MEITUAN_TRACKER_HOME:-$HOME/hk-stock-tracker}}/hk_stock_tracker/tracker.py" init --code 0700
python3 "${HK_STOCK_TRACKER_HOME:-${MEITUAN_TRACKER_HOME:-$HOME/hk-stock-tracker}}/hk_stock_tracker/tracker.py" daily --code 0700
python3 "${HK_STOCK_TRACKER_HOME:-${MEITUAN_TRACKER_HOME:-$HOME/hk-stock-tracker}}/hk_stock_tracker/tracker.py" intraday --code 0700
```

- `--code` 支持 `700`、`0700`、`00700`、`700.HK`，内部统一为 5 位港股代码。
- `3690` 继续沿用旧的 `data/`、`reports/`，不迁移、不破坏既有连续数据。
- 其他代码使用独立目录：`data/<5位代码>/`、`reports/<5位代码>/`。
- 新代码的 `init` 只生成“关键位草稿”，会在配置与报告中标记 `auto_generated: true`。未人工校准前，只做结构观察；程序抑制草稿关键位的日线 playbook 和日内做 T 信号。
- 每个标的可配置 `benchmark`（默认新标的 `hkHSI`，美团仍是 `hkHSTECH`）、`chip_bin_width`、`intraday_bin_width`。未配置时按价格自适应，避免低价/高价股分箱失真。

- 收盘后跑（普通日 16:10、半日市 12:10 后，含收市竞价）；盘中跑会标注"盘中未收盘"，缺失换手用此前有效数据估算，收盘后重跑自动覆盖。
- 幂等：同日重跑覆盖当日快照；周末/节假日提示"无新交易日"不落盘。

## 文件

| 文件 | 内容 |
|---|---|

## 解读框架（每日报告怎么看）

1. **获利盘**：<10% = 深度套牢区（抛压衰竭但也说明趋势弱）；>90% = 获利了结压力大。美团基线 6.5%，属极端套牢。
2. **集中度**：90% 口径 <10% 为高度集中，>25% 为分散。基线 27.6%，筹码分散。
3. **筹码峰**：峰位 = 压力/支撑。现价上方的峰是解套抛压（距离近的先压制），下方的峰是支撑。峰位迁移（主峰从高位移到低位）是底部夯实的核心信号。
4. **换手率**：20 日均 <0.5% 为缩量（底部特征之一）；>0.8% 且价格站稳关键位 = 有效放量；单日 >2× 20 日均 = 异动，必须结合价格方向解读。
5. **事件栏**：为空 = 无结构变化，沿用既有立场；出现关键位突破/跌破时才需要重新决策。
6. **沽空比例**（数据源 ETNet，约 16:35 更新当日数据）：卖空金额/当日总成交额。港股大盘常态 10-20%；>25% 为激进做空。必须结合价格行为解读：飙升+跌破支撑 = 空头进攻确认（看跌）；飙升+价格守住支撑 = 潜在逼空燃料；高位骤降+收涨 = 空头回补助推。注意港股沽空含做市商衍生品对冲，单看比例有噪音。
7. **南向资金**（数据源东财 RPT_MUTUAL_STOCK_HOLDRANKS，T+1 滞后）：港股通持股与每日增减。四象限解读：价跌+增持=内资接盘（底部支撑）；价涨+减持=兑现（反弹质量存疑）；价涨+增持=内外资共振（最健康）；价跌+减持=同撤（弱势确认）。南向是趋势资金，单日意义小、连续方向意义大。
8. **技术状态**：MA 排列判断趋势背景；ADX(14) 给出市型背景（<20 震荡、>25 趋势、20–25 过渡）；程序不按市型自动筛选规则或改变仓位；MACD/OBV 底背离 = 吸筹特征；布林带宽处于 60 日最低 10% = 波动率挤压、变盘临近；赔率比 = 阻力距离/支撑距离；带 `action: entry` 的规则在赔率小于 1 或缺乏支撑/阻力时不会触发，未标记为 entry 的规则不应用这一门槛。
9. **多信号矛盾时**：立场以观望为默认，矛盾信号（如沽空高+南向撤+MACD收敛）如实列出，不强行给方向。

## 战略地图（2026-10-23 基线，存于 levels.json）

- **阻力**：72.3（最近套牢峰 6.9%）→ 78.3（主峰 13.0%）→ 83.8 → 86.3 → 92.3
- **支撑**：70.5（薄）→ 67.5（66-69 次级带）→ 63.65（52周低）→ 62.5（60-65 历史铁底，2018-2020 累计 31 亿股换手区）
- **playbook**：
  - 右侧：收盘高于 72.3 且放量、收盘高于 78.3 时属于单日条件触发；两日确认尚未实现或回测验证 → 跌回 70 下方放量则证伪
  - 左侧：66-69 第一批（1/3~1/2 计划仓）→ 60-65 第二批 → 有效跌破 58 证伪离场
  - 箱体：66-78 有效期间 67-69 接 / 77-78 减，放量破位即停用

## 回测使用原则

2026-10-23 的历史回测存在数据可用时间和换手率填补问题，其统计结果保留在旧报告中作为历史记录，**不能再作为信号有效性或交易建议的依据**。需使用更新后的回测重新核验，报告也应说明数据时间、前复权与交易成本等限制。

默认运行 `python3 "${HK_STOCK_TRACKER_HOME:-${MEITUAN_TRACKER_HOME:-$HOME/hk-stock-tracker}}/hk_stock_tracker/backtest.py"`，使用港股时区的当天作为截止日期，盘中会排除今日未收盘 K 线；可用 `--end YYYY-MM-DD` 或 `--output PATH` 指定范围和输出。已有同名报告不会被覆盖；仅在明确需要覆盖时使用 `--overwrite`。回测以信号日收盘计算理论收益，未扣交易成本，不等同于可执行收益。南向和沽空数据保守后移一个交易日，但实际发布时间仍需核验。

盘中 `close_*` 条件不触发；换手估算时相关放量条件不触发。快照和日报先写恢复记录，再分别原子替换；中断后下一次同标的任务启动时尝试恢复，外部修改冲突时保留记录并停止。写入中不受锁约束的读者可能暂时看到不同步；此机制不保证断电后的所有文件系统行为。同一标的任务使用进程锁，冲突时新任务退出，不同标的可并行。

## 每日分析规程

1. 执行上面的 daily 命令，先看事件栏：有事件→对照 playbook 给行动建议；无事件→一句话确认"结构未变，维持观望/既有立场"，不强行给建议。
2. 建议必须引用具体价位和筹码依据（如"78.3 主峰未收复前，反弹到 77-78 是减仓区"），不说空话。
3. 区分受众立场：空仓看右侧/左侧买点，被套按成本区间给减仓/做T思路（成本 78-86 逢反弹减，90+ 要评估基本面逻辑而非死等解套）。
4. **每月或主峰迁移时**：重算后更新 levels.json，并在 docs/JOURNAL.md 记一条结构变化（旧峰/新峰、获利盘趋势、判断依据）。
5. **每周**在 docs/JOURNAL.md 补一句复盘：本周建议 vs 实际走势，规则误判要记录并考虑调整 playbook。
6. 筹码面不覆盖基本面：外卖/即时零售竞争、财报（季报）、监管动态会改变结构本身。财报日前后提示事件风险，建议用户结合基本面决策仓位。

## 日内分析（intraday 子命令）

用户问"美团今天能T吗/日内怎么操作/盘中怎么看"时用。数据：腾讯逐分钟（minute/query）+ 恒生科技指数（hkHSTECH）+ 日K ATR。

**指标解读**：

1. **VWAP**：机构交易基准。价在 VWAP 上方且斜率向上 = 日内强；下方 = 弱，反弹到 VWAP 附近是减仓窗；偏离 >2σ 不追，等回归。
2. **分时筹码（1港元箱）**：POC 是当日多空主战场，价在 POC 上方 = 当日进场者多数浮盈（心态稳）；70% 价值区是日内合理波动带。
3. **ORB 开盘区间**：9:30-10:00 区间放量上破可顺向小仓；15 分钟内回落区间 = 假突破，立即认错。港股开盘波动大，假突破多。
4. **RVOL（投影口径）**：>1.5 = 明显放量，配合方向解读；<0.7 = 缩量，日内大概率无行情。
5. **超额强弱**：美团涨跌幅 − 恒生科技涨跌幅。|超额| >1% = 个股独立行情，必有个股消息/资金行为，追单前先想原因。
6. **ATR 空间**：已走振幅 >1.2×ATR(14日) = 日内空间大概率走完，不追单。
7. **关键位触发**：报告会给出今日触及关键位的时间与量能倍数——触及 72.3 等阻力位时量能 ≥2× 且滞涨 = 抛压真实存在。

**日内 playbook**（规则引擎已内置，输出立场时按其解读）：

- **做T（仅限已持仓者降低成本）**：只在关键位做。反弹至 72.3/78.3 且 5min 放量滞涨 → 减；回踩 70.5/67.5 缩量止跌 → 接回。单次 ≤1/3 仓，当日了结，止损 1-1.5%。非关键位不动手。
- **时间纪律**：9:30-10:00 不定方向不重仓；14:00 后仍无量则今日放弃；临近 15:00（A股收盘，南向资金切换）不追单。
- **风控铁律**：日内单笔止损 1-1.5%，日亏损上限 3%。港股 T+0 无涨跌停，止损必须机械执行，不许"再看看"。

**日内与日线的关系**：日内信号服务于日线战略地图——日线判方向（深套+上方层层压力=只低吸不追高），日内只解决"什么时候低吸、什么时候T"的执行问题。日内信号与日线结构冲突时，以日线为准。

## 交易日历

内置 HKEX 证券市场 2023–2027 休市和半日市安排。普通日到 16:10、半日市到 12:10 后才视为收市；未覆盖年份需更新 `hk_calendar.py`。静态日历不覆盖极端天气、临时停市或个股停牌，需核验数据源和 HKEX 公告。

## 健康检查

- snapshots.csv 最后日期应是最新交易日；连续 3 个交易日未更新说明 cron 或数据源有问题。
- 腾讯接口偶发失败：重跑一次即可；连续失败查网络或接口变更（字段格式变化需修改 `hk_stock_tracker/tracker.py` 解析）。
- 沽空数据来自 ETNet（quote_shortsell.php?code=3690，约 40 日历史）：当日数据收市后约 16:35 更新；**该服务器响应慢，抓取已内置 60s×2 重试**，盘中临时值带 `*` 前缀（次日终值自动覆盖）；页面表格失效时兜底解析内嵌 drawComboChart2 JS 数组；备用数组的卖空金额是股数×收盘价估算，报告标记估算、快照金额留空。连续失败按此顺序排查：超时→grep "Trading Date"→grep "drawComboChart2"。
- 南向数据来自东财 datacenter-web API（RPT_MUTUAL_STOCK_HOLDRANKS，T+1 滞后，需 Referer 头）：失败时自动跳过；注意该接口偶发限流，重试即可。
- levels.json 手改后次日即生效，无需改代码。
